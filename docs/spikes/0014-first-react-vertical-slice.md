# 0014 — First React Vertical Slice

- Date: September 9, 2026
- Result: Pass (local implementation)
- Related decision: `docs/decisions/0001-runtime-and-services.md`

## Question

Can the deliberately built application replace the first part of the frozen walking skeleton with a typed, browser-only production-details and exact-PDF-preview flow?

## Approved scope

The project owner approved these fields for the first local slice:

- production or producer name;
- optional signature collector;
- production email;
- project title; and
- agreement date, defaulted to the device's local calendar date and correctable later by the signer.

Release text is a locked synthetic fixture. It is visibly and repeatedly identified as test content rather than editable or usable legal language.

## Behavior

The React application:

1. validates the approved production fields in the browser;
2. displays the complete locked test release text;
3. generates a PDF locally from the entered fields;
4. fully parses the generated bytes against the three-page and 3,000,000-byte browser contract;
5. displays those exact bytes in an embedded PDF preview; and
6. permits a local test download or a return to editing, which discards the old preview URL.

PDF construction and parsing code is loaded only when preview generation is requested. The initial form does not upload, persist, email, or seal any data. The interface states these limits rather than simulating success.

## Evidence

On September 9, 2026:

- the production dependency audit reported zero vulnerabilities;
- all 91 tests across eighteen files passed before the final code-splitting pass;
- field-schema tests rejected an unapproved editable-release field;
- the generated fixture parsed as a one-page PDF and passed the browser PDF contract;
- TypeScript checks passed for production, tests, the React application, and the retained browser spike; and
- Vite produced the production browser bundle successfully.

## Remaining gates

- Run the interface manually in current desktop and mobile browsers.
- Add signer handoff, signer identity fields, photo capture, and vector signature in separate reviewed slices.
- Replace synthetic text only after reviewed release and privacy language is supplied and approved.
- Do not connect the local multipart adapter to a public Worker; its Free CPU gate failed in spike 0013.
- Define and test abuse prevention before any finalization or email endpoint becomes public.

## Conclusion

This is the first interactive slice of the deliberately built application, not an extension of the Lovable reference and not a simulation of sealing. It replaces production setup and exact local document preview with owned, typed, tested code while keeping unfinished behavior explicit.
